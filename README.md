
# Robust and Explainable Emotion Classification

## Research Overview

This project investigates the robustness and reliability of classical machine learning and transformer-based models for multi-label emotion classification. The study uses Google's GoEmotions dataset.

## Research Areas

- Natural Language Processing
- Machine Learning
- Deep Learning
- Multi-label Classification
- Model Robustness
- Explainable AI

## Research Objectives

1. Compare classical ML and Transformer models.
2. Evaluate performance across emotion categories.
3. Investigate robustness against linguistic perturbations.
4. Explore data augmentation techniques.
5. Evaluate model calibration and interpretability.

## Dataset

GoEmotions – Google Research

https://github.com/google-research/google-research/tree/master/goemotions

The dataset contains 27 emotion categories and a neutral category.

## Models

- Logistic Regression
- Linear SVM
- Multinomial Naive Bayes
- DistilBERT
- BERT

## Evaluation Metrics

- Macro F1
- Micro F1
- Precision
- Recall
- Hamming Loss
- Jaccard Score
- Expected Calibration Error

## Technology Stack

Python, Pandas, NumPy, Scikit-learn, PyTorch, Hugging Face Transformers, Matplotlib and Seaborn.
